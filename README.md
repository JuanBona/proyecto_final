# Proyecto Final

Monorepo (API NestJS + web Next.js) para el proyecto final.

## Desarrollo local

1. Instalar dependencias:

```bash
npm install
```

2. (Opcional) copiar variables:

```bash
cp .env.example .env
```

3. Ejecutar ambos servicios:

```bash
npm run dev
```

Contrato de puertos en desarrollo:
- Web: `3000`
- API: `3001` por defecto (sobrescribible con `API_PORT`)
